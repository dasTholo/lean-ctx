## Quellenlogik und Evidenzqualität

- `[PRIMARY]` bezeichnet offizielle Studien, Audits, Gerichtsentscheidungen, Produktdokumentation oder Anbieter-Telemetrie mit beschriebener Methodik.
- `[ANALYST]` bezeichnet Gartner, Forrester, McKinsey, Deloitte oder vergleichbare Analysten; Prognosen werden nicht als Ist-Daten ausgegeben.
- `[VENDOR-SURVEY]` bezeichnet eine von einem Anbieter beauftragte oder veröffentlichte Befragung; sie ist ein Signal, kein neutraler Markt-Census.
- `[COMMUNITY]` bezeichnet ein öffentliches GitHub issue oder einen Nutzerreport; es belegt einen beobachteten Fall, nicht die universelle Framework-Eigenschaft.
- `[INFERENCE]` markiert eine Ableitung aus mehreren Quellen und ist keine wörtliche Aussage einer Quelle.
- Jede faktische Zeile enthält eine direkte URL, damit die Aussage außerhalb dieses Dossiers überprüfbar bleibt.
- Um Copyright einzuhalten, werden kurze direkte Zitate verwendet und längere Inhalte paraphrasiert.
- Vendor-Fundraising wird als Nachfrage- und Kapitalmarkt-Signal interpretiert, nicht als Beweis für Produktqualität.
- Framework-Probleme werden als dokumentierte Trade-offs oder konkrete Issues formuliert, nicht als pauschales „Framework X ist schlecht“.
- Survey-Prozentwerte sind populationsgebunden; sie dürfen nicht ohne Stichprobe als allgemeine Enterprise-Wahrheit gelesen werden.
- Eine „failed deployment“ kann ein kompletter Rollback, ein Audit-Failure, ein Liability-Fall, eine unzuverlässige Antwort oder nur ein offen gemeldeter Incident sein.
- „Agent“ wird hier für Systeme mit multi-step control flow, tool execution, state oder mehreren service calls verwendet. [Quelle: Datadog](https://www.datadoghq.com/state-of-ai-engineering/)
- Klassische single-turn chatbots werden nur dann eingeschlossen, wenn ihr Fehlverhalten direkt eine agentic deployment lesson liefert.
- Zeitangaben beziehen sich auf den Veröffentlichungszeitpunkt der Quelle, sofern nicht ausdrücklich ein Ereigniszeitpunkt genannt wird.
- Die stärksten Belege für den Context-Schmerz sind die Kombination aus Analystenwarnung, Produktions-Telemetrie, Framework-Design und realen Vorfällen.

## 1. Marktbild: Adoption steigt, Production skaliert nicht automatisch

- McKinsey fand Ende 2025, dass 88% der Befragten AI regelmäßig in mindestens einer business function nutzen. [Quelle: McKinsey](https://www.mckinsey.com/capabilities/quantumblack/our-insights/the-state-of-ai?os=shmmfp)

- **Integration:** Agents müssen APIs, identity providers, data stores, ticketing, CRM, ERP und legacy systems verbinden; jede Schnittstelle erweitert den Failure surface. [Quelle: McKinsey](https://www.mckinsey.com/industries/technology-media-and-telecommunications/our-insights/reimagining-the-value-proposition-of-tech-services-for-agentic-ai)
- **Integration:** Google Cloud identifiziert legacy API/data integration als größte Infrastruktur-Lücke für 43% der IT leaders. [Quelle: Google Cloud](https://cloud.google.com/blog/topics/ai-infrastructure/state-of-ai-infrastructure-report-and-the-agentic-data-cloud)
- **Integration:** 81% der Google-Cloud-Befragten nannten operational complexity und engineering overhead beim Patching disconnected agents als Top unforeseen expense. [Quelle: Google Cloud](https://cloud.google.com/blog/topics/ai-infrastructure/state-of-ai-infrastructure-report-and-the-agentic-data-cloud)
- **Integration:** Ein Agent kann technisch einen Tool call ausführen, aber ohne policy-aware API ist nicht geklärt, ob er es darf. [INFERENCE; Quelle: Gartner](https://www.gartner.com/en/newsroom/press-releases/2026-04-02-gartner-expects-most-enterprises-to-abandon-assistive-ai-for-outcome-focused-workflow-by-2028)
- **Data quality:** KPMG nennt data quality als drittgrößte Deployment-Hürde nach cybersecurity und data privacy. [Quelle: KPMG](https://kpmg.com/kpmg-us/content/dam/kpmg/pdf/2026/ai-quarterly-pulse-survey-q4-2025.pdf)
- **Data quality:** Qlik findet data quality, data availability und data access als Top barriers; erst danach kommen integration, skills und governance. - **Data readiness:** 46% der Qlik-Befragten erwarteten erst in drei bis fünf Jahren Scale. [Quelle: Qlik](https://www.qlik.com/us/news/company/press-room/press-releases/qlik-2025-agentic-ai-study-budgets-surge-but-data-readiness-delays-scale)

- **Security:** McKinsey nennt agent security vulnerabilities als eine der drei core challenges in der C-suite-Befragung. [Quelle: McKinsey](https://www.mckinsey.com/industries/technology-media-and-telecommunications/our-insights/reimagining-the-value-proposition-of-tech-services-for-agentic-ai)

[Quelle: McKinsey](https://www.mckinsey.com/capabilities/risk-and-resilience/our-insights/securing-the-agentic-enterprise-opportunities-for-cybersecurity-providers)
