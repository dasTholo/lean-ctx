# v0.1.0 Bootstrap-Findings (Task 18, redefined)

Datum: 2026-05-24

## Original-Scope (infeasible)

Spec §12.2/§12.3/§12.4 sahen Live-MCP-Tests via `mai render` vor:
- Cold/Hot Cache-Hits
- Service-Fail Test
- Lang-Detection-Test

**Befund:** `markdownai`-CLI ist eine **static-transformation tool** — sie führt KEINE
`@query`-Direktiven gegen live MCP aus. stderr-Output:

```
@query command blocked [not_allowed]
```

Quelltext-Beleg: `markdownai/packages/engine/src/engine-include.ts` zeigt, dass
`@query` nur ge-parst aber nicht executed wird (security-policy-Block).

→ **Live-Bootstrap-Tests sind aus dem CLI nicht ausführbar.** Spec §14 hat das
als Risk gelistet; in v0.1.0 wird der Scope reduziert.

## Frontmatter-Leak Fix (Patch in Task 18)

**Befund Task 17:** `mode: include`-Files (`hard-rules.md`, `tool-quick-ref.md`)
leakten ihre YAML-Frontmatter (`---lib_version:0.1.0\nmdai-pack:...\n---`) als
Text in den Render-Output.

**Ursache:** `executeInclude` (engine-include.ts:71-110) walked alle AST-Nodes
inklusive Text-Nodes. Frontmatter wird vom Parser nicht gestrippt.

**Fix v0.1.0:**
- Entfernung der YAML-Frontmatter aus `mdai/core/hard-rules.md` und
  `mdai/core/tool-quick-ref.md`.
- Convention-Update in `mdai/MACROS.md`: Mode-Bestimmung erfolgt am Use-Site
  via `@include` vs. `@import`. `mode`-Feld in der Inventar-Tabelle bleibt als
  dokumentarisches Marker, ist aber für mai-CLI semantisch irrelevant.

**Verifikation:** Smoke-Test re-run (Step 18.4) zeigt 0 Hits für `^lib_version`
in Render-Output; `## Hard Rules` weiterhin sichtbar.

## Bekannte Limitationen v0.1.0

1. **mai CLI führt keine `@query`-Direktiven aus.** Live-Bootstrap-Tests
   (cache/service-fail/lang-detection) sind nur möglich aus einer Claude-Code-
   Session mit aktiven MCP-Servern — nicht aus dem CLI-render.
2. **`ctx_session` ist kein key-value-Store.** Caching im `mdai_bootstrap`-
   Orchestrator wurde in v0.1.0 entfernt; jeder Bootstrap-Aufruf re-läuft
   die Probes (Spec §14 Risk akzeptiert).
3. **Frontmatter-Convention:** `mode: include`-Files dürfen keine YAML-
   Frontmatter tragen. Dokumentiert in MACROS.md.
