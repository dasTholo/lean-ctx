## Verifikations-Harness (gilt für ALLE Tasks)

Diese Mechanik wird in den Task-Steps referenziert — hier einmal zentral, nicht pro Step wiederholt.

**MCP (primär, `cwd` = Repo-Root `/home/tholo/Scripts/lean-ctx`):**

- Macro-Smoke: `mcp__markdownai__call_macro(file="mdai/<pfad>.md", macro="<name>", args={…})`
- Phasen-Smoke: `mcp__markdownai__resolve_phase(file="mdai/skills/mdai-brainstorm/body.mdai.md", phase="<id>")`
- Directive-Check: `mcp__markdownai__execute_directive(directive="@<…>")` — **erlaubt nur** `env, define, call, list, read, date, count, tree, event`. `@eval`/`now_iso()` ist MCP-seitig **gesperrt** → nur via CLI testbar.
- Katalog: `mcp__markdownai__available_directives()`

**CLI (`validate` + voller Render), aus dem Repo-Root, NICHT aus `markdownai/`:**

- `npx --prefix markdownai mai validate <pfad-relativ-zur-repo-root>`
- `npx --prefix markdownai mai render <pfad-relativ-zur-repo-root>`
- **Wichtig:** `cd markdownai && npx mai render "../<pfad>"` schlägt mit `Path traversal above document root is not permitted` fehl. Immer aus Repo-Root rendern. (Dieser Traversal-Block betrifft auch `render_spec` in `write-spec.md` — siehe Task 5 / Risiken.)

**Konventionen (aus `CLAUDE.md`, zwingend):**

- Vor jedem `git add`: `mcp__jetbrains__reformat_file(<geänderte-datei>)` auf JEDE geänderte Datei.
- **Keine** `&&`-Bash-Ketten — jeden Befehl einzeln absetzen.
- `git add <datei>` per Name, nie `git add -A`/`.`.
- Commit-Message per HEREDOC, Trailer `Co-Authored-By: Claude Opus 4.7 (1M context) <noreply@anthropic.com>`.
- Wegwerf-Smoke-Files nur unter `.tmp-bt/` (gitignored), nie committen.
- Chat/Plan/Commits: Deutsch; Code/Code-Kommentare: Englisch.

**v2-Syntax-Regeln (die drei Lücken — gelten projektweit):**

1. **Predicate-Call-Form:** `file.exists "x"` → `file.exists("x")`; `file.containsLine "a" "b"` → `file.containsLine("a", "b")` (Klammer + Komma).
2. **Quoting-Regel für Predicate-Args:**
   - Reine Variable `"{{ var }}"` → **unquoted**: `file.exists({{ var }})`.
   - String-Literal mit eingebetteter Interpolation `"docs/…/{{ slug }}-x.md"` → **quoted bleiben** (Interpolation läuft vor der Predicate-Auswertung, Ergebnis ist ein String): `file.exists("docs/…/{{ slug }}-x.md")`.
   - Reines String-Literal `"Cargo.toml"` → **quoted bleiben**: `file.exists("Cargo.toml")`.
3. **`@foreach`-Source** muss interpoliert sein: `@foreach x in liste` → `@foreach x in {{ liste }}`.
4. `matches` ist **infix** (`@if @result.stdout matches "…"`) — laut Re-Validierung **nicht** betroffen; in Task 1 per Smoke bestätigen, sonst unverändert lassen.
