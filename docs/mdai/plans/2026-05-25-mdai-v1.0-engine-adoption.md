# markdownai v1.0 Engine-Adoption — Implementation Plan (Part 1 / 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Subagent-Modell-Politik (festgehalten per User-Anweisung):**
> - Default-Modell für ALLE Subagent-Dispatches: **`sonnet`** (Anthropic Sonnet).
> - Ausnahme: Phase 1 (Engine-Bump + respondTool-Empirik) DARF bei Bedarf auf
>   **`opus`** hochgezogen werden (höhere Reasoning-Kapazität für Merge-Konflikt-Resolution).
>   Default bleibt sonnet — Opus nur, wenn Sonnet einen konkreten Reasoning-Schritt nicht löst.
> - Beim Dispatch über `Agent`/`TaskCreate`: `model: sonnet` (bzw. `opus` für P1 nach Bedarf) immer explizit setzen.
> - Tool-Allowlist pro Subagent: Serena-Tools + lean-ctx (`ctx_*`) + JetBrains-MCP + `mcp__markdownai__*`. Kein `Bash` außer wo explizit erlaubt (z.B. `git`, `npm`, `node`).

**Goal:** markdownai-Engine von lokalem `feat-mdai`-Stand (Patch über 0.0.24) auf upstream **v1.0.0** bumpen, v1.0-Hook-Infrastruktur installieren, und alle `@include`/`@import`-Pfade in der mdai-Library auf `${MDAI_LIBRARY_ROOT}`-Globs migrieren — der Engine-Resolver-Patch aus der alten Vorgänger-Spec wird damit **obsolet** (config-only).

**Architecture:** Drei sequentielle Phasen mit hartem Gate nach jeder Phase: P1 Engine-Bump + npm link, P2 Hook-Reinstall (PreToolUse-ironclad + SessionStart), P3 `source_root`/`data_root` Config-Migration. P1 ist hartes Gate (Spec §2.2). Plan 2 (`docs/mdai/plans/2026-05-25-mdai-brainstorm-v0.1.1-refactor.md`) baut auf dem Endzustand dieses Plans auf.

**Tech Stack:** Node 20+ (markdownai engine/parser/mcp/core via npm workspaces), Bash (git/npm/node-CLI), MCP-Server `markdownai` + `lean-ctx` + `serena` + `jetbrains`. Verifikation ausschließlich via `mcp__markdownai__*` (resolve_phase / list_phases / read_file) + `ctx_search` für Anti-Pattern-Sweeps.

**Spec:** `docs/mdai/specs/2026-05-25-mdai-v1.0-adoption-design.mdai.md` — Abschnitte §1–§5 + §9/§10 (Verifikation, Risiken).

**Successor-Plan:** `docs/mdai/plans/2026-05-25-mdai-brainstorm-v0.1.1-refactor.md`
