## Konsolidierte Beobachtungen

### Recurring Tool-Call-Pattern (verbatim, ≥3 erfasst)

1. `@query mcp__lean-ctx__ctx_read path="<abs-path>" mode="full"` — 8× über RL1/RL2/RL3 hinweg (RL1: 1×, RL2: 3×, RL3:
   3×, +RL1 Cargo.toml). Identisches Schema, nur `path` variiert; kein Agent prüfte, ob `mode="map"` effizienter wäre.

2. `@query mcp__jetbrains__reformat_file path="<abs-path>"` gefolgt von
   `@query mcp__lean-ctx__ctx_shell command="git add <rel-path>"` gefolgt von
   `@query mcp__lean-ctx__ctx_shell command="git commit -m '...'"` — Dreier-Block in RL1 1×, RL2 2×, RL3 2× = 5
   Vorkommen des identischen strukturellen Musters, Copy-Paste ohne Abstraktion.

3. `@query mcp__lean-ctx__ctx_shell command="git status"` (oder Variante mit `-C`) — in allen 3 Reports exakt 1×
   vorhanden, stets in der Phase vor dem Commit-Block. Pattern: git-status-Check erscheint genau einmal pro Plan, aber
   die Schreibweise divergiert (RL1/RL2: `git status`, RL3: `git -C /home/tholo/Scripts/lean-ctx status`).

4. `@query mcp__lean-ctx__ctx_search pattern="<pattern>" path="/home/tholo/Scripts/lean-ctx/src"` — 2× in RL1, 2× in
   RL2, 2× in RL3 = 6 Vorkommen. Identisches Pfad-Schema, wechselnde Patterns (TODO/FIXME/`pub fn`/`fn `/`use `). Kein
   Agent nutzte eine Abstraktion für den gemeinsamen `path`-Parameter.

### Drift-Pattern

- **ctx_read mode-Inkonsistenz:** RL1 nutzt `mode="full"` für Cargo.toml und `mode="map"` für CHANGELOG.md (2
  verschiedene modes für ähnliche Config-Dateien). RL2 und RL3 nutzen ausnahmslos `mode="full"` für alle Reads (auch
  große Dateien). Cross-Report: 3 Agents, 2 verschiedene mode-Strategien ohne Konvention.

- **git-Befehlssyntax-Divergenz:** RL1 und RL2 schreiben `git status` (implizites cwd). RL3 schreibt
  `git -C /home/tholo/Scripts/lean-ctx status` (expliziter absoluter Pfad via `-C`). Gleiche Semantik, drei syntaktische
  Varianten — ohne GIT_ROOT-Macro nicht determinierbar.

- **Pfad-Inkonsistenz absolut/relativ im selben Block:** RL2 und RL3 schreiben
  `reformat_file path="/abs/path/src/lib.rs"` (absolut) direkt gefolgt von `git add src/lib.rs` (relativ). Gleiche
  Datei, zwei Pfad-Konventionen innerhalb von 3 aufeinanderfolgenden Zeilen.

- **Commit-Message-Scope-Drift:** RL1 und RL2 schreiben Conventional Commits ohne Scope (`fix: ...`, `refactor: ...`).
  RL3 schreibt mit Scope (`fix(main): ...`, `refactor(lib): ...`). Alle 3 Agents zufällig im Conventional-Commit-Format,
  aber ohne Template-Erzwingung inkonsistenter Scope-Gebrauch.

- **LOC-Overhead durch Pressure:** RL1: 42 LOC / 8 Tool-Calls = 5.25 LOC/Call. RL2: 38 LOC / 12 Calls = 3.2 LOC/Call.
  RL3: 54 LOC / 12 Calls = 4.5 LOC/Call. Authority-Pressure erzeugt mehr Inline-Prosa (+42% vs. RL2 bei gleicher
  Tool-Call-Anzahl).
